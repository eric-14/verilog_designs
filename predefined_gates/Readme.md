# Predefined Gates 

This are the basic gates that are verilog compiles to. They are the gates taught in digital electronics 101 class. 

They include AND, OR, NOR, XNOR, XOR, NAND and NOT GATE. 

## Predefined gates 

The folder contains system verilog defining the gates. The .sv file is compiled using iverilog. Testbench have been created and output can be 
viewed using GTKWave.
